# AquaMacro

**Prima di tutto leggi `PROJECT.md`**: è la mappa completa del progetto (stack, file, modello dati, colori, PWA, Supabase, limiti). Non scorrere tutti i sorgenti: apri solo i file che devi modificare.

Regole:
- Aggiorna `PROJECT.md` quando cambi struttura, modello dati, setup o aggiungi funzioni.
- UI in italiano. Colori solo tramite i token di `app/globals.css`; dentro `.panel` usa i `--p-*`.
- Il repo è pubblico: nessun segreto, nessun dato personale nel codice (i cibi iniziali stanno su Supabase, non nel repo).
- Verifica con `npm run build` (typecheck + CSP).
